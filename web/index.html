About this radio

Without a credential, there is no radio. The door answers 404, not 401 — it does not confirm to anyone that anything exists here. You are let in, or you are not.

Everything you hear is generated by us: no samples, no third-party audio, no royalties. Each track is born from a seed in indiegenerator, a deterministic, offline generator. The same seed produces the same plan and, on the same machine, the same audio, byte for byte. Re-listening to a track is re-running the same number. Determinism is the identity, not a side effect.

This is the tip, not the whole thing. Other sounds, built in weird ways, will land on this same stream. The door does not change; what comes through it does.

How a track is born
  1. A seed (a number) and a lane (motorik, kosmische, ambient, dub-electronic, indie-noise).
  2. indiegenerator composes the plan: sections, motifs, strategies, mix. The plan is hashed (plan_sha256).
  3. The plan is rendered to audio: single thread, BLAS at 1 thread, streamed arrays to stay under 1.5 GB of RAM.
  4. Gates: −16 LUFS, true peak ≤ −1.5 dBTP, MP3 128 without surprises, no clipping. If it fails, it does not get in.
  5. validate → install: atomic copy into music/. The radio never restarts; Liquidsoap picks it up on its own.

The same seed produces the same plan and, on the same machine, the same audio, byte for byte. render --from-plan does not compose: it only re-renders. Determinism is the property, not a side effect.

The five lanes
  • motorik (30%) — 110–140 BPM, Steady Hand / Sixteen Steps.
  • kosmische (25%) — 70–110 BPM, Hollow Signal / Sustained Weather.
  • ambient (20%) — 112–124 BPM, Long Exposure / Rooms in Half Light.
  • dub-electronic (15%) — 100–130 BPM, Silt / Chamber Echoes.
  • indie-noise (10%) — 90–135 BPM, Tin Roof / Loose Ends.

One motif bank, one palette, one 1/f drift, one strategy deck, one tempo centre. The identity is in the sound, not the tag.
